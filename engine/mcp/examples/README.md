# Show tool examples

The six original handcrafted `show` examples, moved here without replacing them
with generated project-data pages. Each opens standalone and inside CallYourCode.

Interactive host-integrated examples:

- `sync-review-question-round.html`: multi-question review with saved drafts and structured submit.
- `release-task-board.html`: editable Now/Next/Later board persisted with `cyc.save()`.
- `deployment-log-viewer.html`: searchable, filtered deployment log with host submission.

Read-only themed visualizations:

- `service-metrics-dashboard.html`: responsive metric tiles and charts rebuilt on theme changes.
- `checkout-flow-diagram.html`: selectable Mermaid diagrams re-rendered on theme changes.
- `request-lifecycle.html`: narrated step-through request flow.
