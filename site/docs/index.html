Install

One line installs everything: Bun if missing, the repo to ~/callyourcode, wiring for every agent it detects, and the services.

curl -fsSL https://callyourcode.com/install.sh | sh

From a checkout already on disk

sh scripts/install.sh --local
sh scripts/install.sh --dry-run   # touches nothing

What you need

Bun (the installer can install it for you). tmux, the default multiplexer, or herdr as the opt-in upgrade. At least one coding agent: Claude Code, Codex, OpenCode or Pi. A path from phone to machine: a Tailscale tailnet away from the desk, or plain localhost on one machine.
